# multimodal_finetuned_representations

Instructions to run the code:

1. Run the `shell/setup_environment.sh` script to set up the environment.
2. Ensure the `PYTHONPATH` is set to the project root, e.g., `export PYTHONPATH=$PYTHONPATH:/path/to/multimodal_finetuned_representations` or by setting the `.vscode/settings.json` file in the project root along with the `.env` file with the `PYTHONPATH` variable.
3. Run any script in the `scripts` folder, e.g., using the bash scripts in the `shell` folder.
